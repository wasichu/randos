# Randos About Page

Add a simple About page and link it from the top navigation.

The navigation label should be:

```text
About
```

## Philosophy Source

Use:

```text
docs/architecture/philosophy.md
```

as the conceptual source for the About page.

The About page should be a distilled, public-facing adaptation of that document.

Do not copy the philosophy document verbatim.

The architecture document should remain the internal canonical philosophy/design reference.

## Tone

The About page should feel:

- calm
- thoughtful
- human
- minimal
- conversational
- non-corporate

Avoid:

- startup marketing language
- hype
- feature dumping
- growth/productivity framing
- investor-style messaging

The page should feel aligned with the emotional tone of the app itself.

## Content Direction

Explain that Randos is:

- anonymous
- audio-only
- focused on lightweight language conversation
- designed around low-pressure human interaction
- intentionally minimal
- ephemeral by default

Mention ideas such as:

- no accounts
- no profiles
- no followers
- no feeds
- no streaks
- no gamification
- no permanent social graph
- conversations are private and not stored
- users can leave instantly at any time
- conversations continue only through mutual extension

Frame the app as closer to conversational infrastructure than social media.

Explain that the app naturally supports:

- crosstalk
- language exchange
- listening practice
- casual conversation

without forcing users into rigid modes or labels.

## Layout

Keep the page visually simple and readable.

Prefer:

- moderate line width
- comfortable spacing
- restrained typography
- minimal decoration

Do not turn it into a giant marketing landing page.

Avoid:

- hero sections
- giant feature grids
- testimonials
- pricing-style layouts
- excessive call-to-action UI

## Navigation

Add an About link to the top navigation/header.

Keep the navigation minimal.

## Constraints

Do not redesign the rest of the app.

Do not add authentication, profile references, or future social features.

Keep the page understated and aligned with the existing app philosophy.
