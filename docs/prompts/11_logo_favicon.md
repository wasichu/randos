# Randos Logo and Favicon Pass

Add a simple, minimal logo and favicon for Randos.

The visual identity should feel:

- calm
- lightweight
- conversational
- audio-focused
- non-corporate
- non-gamified

## Direction

The current microphone icon is a good starting point.

Create a slightly more custom version or a simple mark inspired by:

- microphone silhouette
- audio waveforms
- conversational audio
- minimal signal imagery

Avoid:

- mascot logos
- cartoon aesthetics
- startup gradient branding
- flashy gaming visuals
- overly polished corporate design

## Requirements

Add:

- site logo for the navbar/header
- favicon
- proper favicon wiring in layouts/root.html.heex or equivalent

The logo should work well in:

- dark mode
- small sizes
- mobile header layout

Keep the design simple and restrained.

SVG preferred if practical.

## Constraints

Do not redesign the app.

Do not add branding clutter.

The logo should feel understated and functional.
