already used the four-second ICE patch. No released recovery regression is

- Qualify the exact version-bump commit with local precommit and sequential
  browser/TUI smoke, green native CI, and an independent release review.
- Require both native CI package builds before publication and verify the
  exact committed production-image candidate.
- Tag the qualified commit, verify published archive bytes/checksums, update
  Homebrew from published hashes and test the installed macOS package.
- Use guarded `just deploy` from a clean, pushed, green-CI checkout and verify
