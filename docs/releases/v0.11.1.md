# randos v0.11.1

A maintenance release with a more compact mobile call screen and updated
terminal-client dependencies.

- On phones, smaller branding and fewer repeated progress labels bring the
  conversation and its controls higher on the screen. Both voices appear side
  by side, with Mute, Next rando and End in one row.
- Connection presentation is simpler, and End has clearer contrast in dark
  mode. Long translated call-control labels wrap within their buttons,
  including when switching between Mute and Unmute.
- The terminal renderer updates pulldown-cmark to 0.13.6 for
  RUSTSEC-2026-0433, while retaining randos' physical-redraw patch.
- Terminal-client dependencies include ringbuf 0.6, realfft 3.5.1 and
  Slipstream 1.3.0. Development and evaluation dependencies are also refreshed.

Call timing, invitations, language matching and the participant protocol are
unchanged. Voice masking stays local and off by default, with no new voice
processors or models in the product.

## Installation

Run `brew upgrade wasichu/randos/randos`, or unpack the macOS arm64 or Linux
x86_64 archive and run `bin/randos`. Existing settings remain compatible.
The website update is deployed separately from the terminal archives.
