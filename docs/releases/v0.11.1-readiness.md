## Scope

The delta from v0.11.0 includes mobile call presentation, the renderer's
pulldown-cmark 0.13.6 advisory fix, TUI runtime dependency updates and isolated
development-model/tooling maintenance. The model comparisons and retained
COMET-compatible setuptools pin are recorded under
[roadmap maintenance](../architecture/refactor_plan.md#deferred-decisions-and-maintenance).
There are no new translated message keys, protocol obligations, call timers,
media processors or privacy claims. Existing DSP/ABI/relay-policy evidence
remains applicable.

## Focused review

The independent release advisor found a mobile label-overflow risk and one
stale ringbuf version in the native README. A real-call experiment confirmed
Mute/Unmute text escaping phone-width controls in multiple languages,
including English Unmute at 320 px. The release adds a bounded wrapping fix
and a regression check of text bounds, across all 20 locales, both mute
states, light/dark themes and 320/390/1200 px widths. No translation model
run or hand-filled catalog was needed.

| Candidate | Decision | Reason |
| --- | --- | --- |
| Call/media policy owners | Leave | No ownership, timing or protocol change |
| Shared waveform/media components | Leave | Existing seam remains useful |
| Localized control regression | Merge | Browser smoke must check text inside controls, not just page overflow |
| Renderer/model evidence | Link | Preserve provenance and comparisons in their authoritative guides |
| Broad refactor | Leave | No demonstrated release benefit |

README, development and self-hosting prose need no updates: installation,
configuration, public controls and call semantics are unchanged. README
screenshots are refreshed. The native dependency table now matches ringbuf 0.6.
