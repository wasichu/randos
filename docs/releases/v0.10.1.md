# randos v0.10.1

Voice masking in the terminal now adds **80 ms less software buffering**.
Its additional frame offset drops from 220 ms to 140 ms, with the same
Signalsmith processing, voice styles and transformed audio. This is the local
masking component's delay, not a measurement of total call or device latency.

Browser buffering is unchanged. Its audio playback runs independently of the
processing worker, and tests showed that reducing its buffer lost needed margin
against processing stalls.

This release also includes the post-v0.10.0 website fix that remembers speaking
and hearing choices across tabs within the browser session. Microphone preview
and voice masking still start off on a fresh visit.

Developer changes include a shorter current architecture guide with preserved
design history, clearer lab navigation, and retained DSP/model experiments and
listening outcomes. The lab and experimental processors remain development-only;
they do not add production voice options, model downloads or server-side audio.

## Installation

Update with `brew upgrade wasichu/randos/randos`, or unpack the macOS arm64 or
Linux x86_64 archive and run `bin/randos`. Archives include ERTS and the native
audio helper, with SHA-256 checksum files. Linux requires glibc 2.39 or newer,
ALSA, OpenSSL 3 and the system C++ standard library.
