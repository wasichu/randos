# v0.11.2 release qualification

The owner authorized a patch release on 2026-11-13 after reviewing the search
animation and web/TUI language rows. Publication is pending qualification.

## Scope and review

This patch changes search-state presentation and aligns terminal setup/search
labels with the website. It adds no protocol messages, client policy, timing,
media processors, dependencies or privacy claims. Prior DSP, ABI and relay-policy
qualification remains applicable.

The TUI imports 35 exact website label translations with their original model
provenance. Three entries retain the same English fallback as the website.
Catalog extraction/merge is model-free; no new translation model run is needed.

The independent release review found no blocking code or privacy issues and
requested direct translated search-state layout coverage before packaging.

| Candidate | Decision | Reason |
| --- | --- | --- |
| Language summaries and cell-width helpers | Leave | Existing owners fit both directions |
| Website label translations | Merge | Reuse approved strings and original provenance |
| Queued web layout regression | Merge | Check new rows directly across locales and viewport sizes |
| DSP, protocol and relay evidence | Link | Ownership and behavior remain unchanged |
| Shared cross-client label runtime | Leave | Separate clients justify separate catalogs |
| Broad refactor | Leave | No demonstrated benefit for this presentation patch |

README, development and self-hosting prose need no changes: installation,
configuration and call semantics are unchanged. Relevant terminal screenshots
are refreshed, and queued web/TUI captures are retained.

## Qualification

- Local precommit and screenshots passed before the version bump. Search motion
  advances, pauses offscreen and respects reduced motion without opening the
  microphone. Light/dark layouts include 1200, 390 and 320 px widths and multiple
  language alternatives.
- TUI render tests keep both language directions visible across all supported
  locales at 80×24, 60×20 and 40×20. Native terminal-buffer checks verify the
  language indentation, including wrapped continuations.
- All 360 queued web layout cases passed: 20 locales, three selection counts,
  three viewport widths and both themes, including RTL. Text bounds stay inside
  headings, language rows and the cancel button; queued search opens no mic.
- Post-commit checks, clean-checkout packaging, native CI, production-image
  inspection, publication and Homebrew validation are pending.
