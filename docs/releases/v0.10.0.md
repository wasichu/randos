# randos v0.10.0

Voice masking is available in both the browser and terminal client. Before a
call, choose **Tone** or **Tone + Pitch**, then **Fuller** or **Brighter**. Use
the local microphone preview to hear the result before talking to someone.
Preview keeps running as you change styles; choosing Off lets you hear your
original voice. Headphones are recommended to avoid feedback.
These styles use signal processing and require no neural-model download.

Masking runs on your device, starts off in each new session, and uses the style
you chose for the next call. Nothing is recorded or uploaded for processing.
These styles change how you sound, but people may still recognize you. They do
not guarantee anonymity against speaker recognition or attempts to reverse the
effect.

The browser homepage has a compact layout and an inline keyboard shortcut bar.
Press **?** to show and activate shortcuts, then **Esc** to hide and disable
them. During a call, **M** mutes, **E** ends the call, and **N** finds another
rando. Invitation calls offer End rather than Next. Letters work in either case.

The terminal client has a language picker on **l** and complete contextual key
help on **?**. Its patched renderer fixes stray characters left behind when
closing the language picker.

The developer audio lab remains local to development builds. It is not included
in the production website.

## Installation

Install or update with Homebrew using `brew install wasichu/randos/randos` or
`brew upgrade randos`. Alternatively, unpack the archive for macOS arm64 or
Linux x86_64 and run `bin/randos`. Each archive includes ERTS and the audio helper;
the `.sha256` files contain its checksum. Linux needs ALSA, OpenSSL 3 and the
system C++ standard library (`libstdc++6` on Ubuntu).
