## Translations

Both catalogs completed the established serial contestants, MetricX/COMET-Kiwi
scorers, Mistral/Qwen judges and automatic-pick pipeline. No rejected candidate
was hand-filled. New labels with no passing pick retain English:

| Client | Locale | New fallback |
| --- | --- | --- |
| Website | Arabic | Speaking-picker guidance: “Pick every language…” |
| TUI | Urdu | Footer key label “preview volume”; the actual volume control is translated |

Existing fallback remains governed by the same pipeline. A context-merge edge
case was fixed in the model-free fill rule: fuzzy copies are treated as machine
text only when the same English and exact prior-machine value prove provenance
in that locale/catalog. Original state is snapshotted, so PO order cannot alter
replacement/clearing. Unknown and edited human values remain protected.
Thirteen focused provenance tests and the full offline suite passed.

## CI timing correction

Candidate `647687d` passed native CI, but a development-only WORLD stream test
incorrectly required playback starvation to prove sustained compute overload.
Its warmup-inclusive cost per output hop was also incorrectly compared against
the largest individual call. `ff7ec5f` preserves the transport, PCM, sample,
queue, clock and explicit-failure guards; separates actual completed-call mean
from warmup-inclusive hop cost; and reports deadline misses without guessing an
unmeasured scheduling cause. Six deterministic regressions and full CI pass.
No processor, production buffer, call behavior or timeout changed. The two
production images have identical filesystem layers apart from commit metadata.

## Scope and retained evidence

The owner confirmed speaker audition becomes audible after raising the new
TUI preview volume, and chose to keep that extra control TUI-only because web
preview already works. This is listening evidence for preview audibility,
not a claim that every historical quiet native call observation is resolved.
No call AGC or AEC default changed. Preview gain stays after decoding, outside
masking input headroom and call audio. Calls freeze their masking profile.
Numeric diagnostics remain opt-in and contain no audio or identifiers.

Local review HTML under `work/review/` was preserved outside the release
candidate. New WAV tests generate explicit synthetic sine fixtures. Existing
Signalsmith core/ABI and relay-policy qualification remains applicable; there
was no new processor promotion, model download or server-side audio.
