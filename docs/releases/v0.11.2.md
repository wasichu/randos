# randos v0.11.2

A small presentation update that makes waiting for a rando clearer.

- The website replaces its half-filled pulsing bar with a search icon and a
  gently orbiting dot. Reduced-motion preferences keep the indicator static;
  decorative motion pauses when the search is offscreen or the tab is hidden.
- Speaking and hearing choices appear as separate labeled rows, with wrapping
  for multiple language selections and narrow screens.
- The terminal client uses the same “I will speak in” and “I want to hear”
  labels as the website. Language lists and their wrapped lines are indented
  below each heading. Existing website translations are reused.

Language matching, call timing and audio behavior are unchanged.

## Installation

Run `brew upgrade wasichu/randos/randos`, or unpack the macOS arm64 or Linux
x86_64 archive and run `bin/randos`. Existing settings remain compatible.
The website update is deployed separately from the terminal archives.
