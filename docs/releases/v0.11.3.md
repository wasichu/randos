# randos v0.11.3

A maintenance release with updated networking, audio-processing and security
dependencies.

- The terminal client's WebRTC and TURN libraries are updated, including
  upstream connection-validation and stream-parser fixes.
- Prompt ICE failure detection is preserved on the updated networking stack.
  v0.11.2 already included this behavior; the regression found during the
  dependency upgrade was corrected before release.
- Echo-cancellation and cryptographic dependencies are updated. Existing
  synthetic echo-cancellation, voice-retention and recovery checks pass; this
  is not a claim of improved physical-device sound quality.
- Dependency fetching and packaging enforce committed lockfiles. CI also
  guards the patched terminal renderer and verifies dependency-update metadata.

The separately deployed website updates Phoenix and LiveView to address their
published security advisories. Call policy, language matching, settings and
local voice-masking choices are unchanged.

## Installation

Run `brew upgrade wasichu/randos/randos`, or unpack the macOS arm64 or Linux
x86_64 archive and run `bin/randos`. Existing settings remain compatible.
